# Database Seeding

FarmPath's application seed implementation is maintained in the **AgriNova-Server** repository.

Please use the existing seed files in the following directory:

[AgriNova-Server/src/database/seed/](https://github.com/Dipteskundu/AgriNova/tree/main/AgriNova-Server/src/database/seed)

This directory contains the project's actual database seeding implementation. Use the instructions and scripts there when preparing or populating the application database.

> Do not use a separate SQL seed file as a replacement for this implementation. The application uses the existing backend seed workflow.
